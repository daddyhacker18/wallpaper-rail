# Wallpaper Rail: problems and ideas

This is where problems and ideas for [Wallpaper Rail](https://mullins1.com/software/wallpaper-rail/) are kept. Wallpaper Rail is a Mac menu bar app that plays your wallpapers like music.

There is no code here. The app is downloaded from [its page](https://mullins1.com/software/wallpaper-rail/), which also says what it needs and what has changed.

## Reporting a problem or suggesting an idea

1. Look through the [open issues](../../issues) first. If yours is already there, add to it rather than opening another: a thumbs-up on the first post, or a comment with anything new.
2. If it is not there, [open a new issue](../../issues/new/choose) and pick **A problem** or **An idea**.

For a problem, the app's log helps a great deal. It is at `~/Library/Logs/Wallpapers.log`.

Everything written here is public. Leave out anything you would not want others to read, such as file paths with your name in them.
